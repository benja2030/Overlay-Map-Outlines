# Overlay Map: Outlines

The pictures for [Overlay Map](https://github.com/benja2030/Overlay-Map-WoW-Forever)'s **Outlines** style: the map's painting hidden, and only white lines for cliffs, water and roads over a dark background, like the overlay maps of other games. A separate download, as the pictures are much bigger than Overlay Map itself. Install it next to Overlay Map; it's loaded only when the style is chosen.

What's in it: one picture per zone of Kalimdor and the Eastern Kingdoms (`Outlines/<map ID>.blp`), made from the game's own terrain: where the ground gets too steep to walk, the edges of the water, and the roads, from the textures the game paints them with.

# Overlay Map: Outlines (español)

Las imágenes del estilo **Outlines** de Overlay Map: la pintura del mapa oculta, y solo líneas blancas de acantilados, agua y caminos sobre un fondo oscuro.
